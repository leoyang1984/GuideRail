# 隐私与本地数据

GuideRail 没有账号、服务器、分析统计、云同步或 AI API 调用，不会上传收藏。

## 读取和保存

- 内容脚本只运行于 `https://chatgpt.com/*`，识别已渲染回复并添加收藏按钮。用户点击后才采集文字和图片。
- 文字、来源和时间写入用户选择的本地文件夹，或通过本机 Obsidian Companion 写入当前 Vault，格式为 Markdown。图片下载到笔记本的附件目录。
- 图片下载会请求页面中已有的图片地址；同源请求可携带当前网站登录凭据。OpenAI 与 Pinterest 图片由扩展后台下载且不携带登录凭据。
- 下载中的图片短期保存在内存，通过扩展消息交给写入器，不持久化在 Chrome 存储中。
- Chrome 的 IndexedDB 保存目录句柄。Companion 模式在 Chrome 本地设置中保存 `127.0.0.1` 地址、Vault 显示名称和随机连接令牌；令牌只发送给本机 Companion。旧版本的数据在用户迁移并选择释放前继续保留。
- 笔记索引、未完成写入记录和迁移备份保存在笔记库的 `.guiderail` 中。索引包含标题、来源、时间、附件路径，不包含完整正文。
- 阅读器从本地 Markdown 和附件读取内容，不加载 Markdown 中任意远程图片或执行嵌入脚本。

## 权限

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 显示侧栏 |
| `tabs` | 打开或定位来源对话及独立设置页面 |
| `storage` | 保存少量设置和兼容旧数据 |
| `images.openai.com`、`*.oaiusercontent.com` | 下载回复中已经显示的 OpenAI 图片 |

Companion 模式通过扩展页面的 `connect-src http://127.0.0.1:*` 安全策略访问本机回环地址。用户点击配对时，Chrome 一次性询问是否允许扩展访问 `http://127.0.0.1/*`；该可选权限不包含局域网其他地址或公网网站。Obsidian 插件只监听 `127.0.0.1`，请求需要一次性配对签发的令牌；插件端只持久化令牌哈希。

文件夹访问通过浏览器系统选择器授权。权限失效会要求重新授权，不会改存到 Chrome 的正文缓存。

## 删除与备份

从列表移除收藏不会删除磁盘文件。切换笔记库、卸载扩展也不会删除所选目录。移动笔记会复制并提交目标位置，再清理原笔记和已知附件；清理失败时保留原位置恢复副本。

迁移清理前先写入并回读校验完整旧数据备份，包含旧任务管理数据。新笔记库的备份方式是复制整个文件夹，包括隐藏的 `.guiderail` 和所有附件。分享笔记或备份前请检查其中的个人内容。

扩展不提供加密；本地文件和浏览器配置的访问保护由操作系统与浏览器负责。代码仓库不应收录个人收藏、图片或备份。
