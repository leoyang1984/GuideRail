# 收藏体验精简实施计划

目标：首次选择文件夹，以后直接收藏、识别和阅读；整理与维护按需出现。

## 推进规则

- 每次只完成一个阶段，阶段内不扩大范围、不顺手重构其他模块。
- 每阶段完成相关回归检查、类型检查和生产构建，再结束本轮。
- 在此文件记录结果与下一步；后续从未完成阶段继续，避免重新分析整个项目。
- 每阶段都交付能使用的 dist，不留下依赖下一阶段才能工作的界面。
- 不自动连续执行后续阶段。用户说“继续下一阶段”时继续。
- 不承诺固定用量；以明确范围和可验收交付控制单轮工作量。

## 阶段 1：阅读页减负

状态：已完成，v0.6.4。

检查：12 项相关回归测试通过；类型检查、生产构建及 diff 空白检查通过。dist 已更新。真实浏览器视觉验收待用户重新加载扩展后查看。

范围：阅读页隐藏保存位置、全局设置、迁移面板和刷新；只保留返回、回到原回复、更多操作。文件路径收进详情；图片和文字按钮统一为“☆ 收藏 / ✓ 已收藏”。

验收：打开收藏即可看标题正文；返回后首页设置仍可访问；既有整理操作可从更多操作进入；图片采集与去重不变。

## 阶段 2：首次设置与首页决策减少

状态：已完成，v0.6.5。

检查：175 项测试通过，覆盖取消选择、独立页回退、默认全部收藏、筛选不改保存位置、兼容旧保存设置、新建文件夹不改保存位置。类型检查与生产构建通过；真实 Chrome 目录授权交互待实测。

- 初始界面只保留“选择保存文件夹”，必要时转独立页，取消后可重试。
- 重授权单独呈现，避免与重新选择目录混在一起。
- 首页默认全部收藏；多个文件夹才显示筛选。
- 浏览筛选不写入后续保存位置；新收藏固定收件箱。
- 创建文件夹入口移到“移动到”，移除“创建并设为保存位置”。

验收：首次未授权不能收藏；筛选和移动不影响下一次收藏位置；老用户的文件和笔记本仍可浏览。

## 阶段 3：识别与整理

状态：已完成，v0.6.6。

实现：列表图片按进入可视区域读取本地预览，离开或卸载时释放对象 URL；文字只读前 8 KB 生成摘要，显示标题截短但不改文件。更多菜单先显示操作名称，选中后才挂载表单，支持 Escape 收起与焦点返回。撤销只修改对应索引条目的隐藏状态，校验原目录与移出操作标记，不覆盖外部编辑。撤销保留当前页面内最近一次移出操作，关闭页面后不保留。

检查：181 项测试通过；类型检查及生产构建通过。覆盖延迟加载后卸载、URL 释放、键盘菜单、外部编辑保护、跨库与过期撤销。真实 Chrome 缩略图与菜单视觉验收仍待查看。

- 图片列表增加本地缩略图；按需读取并释放对象 URL。
- 列表采用短标题及摘要，不改写用户磁盘标题。
- 更多菜单先显示操作名称，选择改标题或移动后才显示对应表单。
- “移出收藏”后提供撤销，保留磁盘文件；撤销只恢复指定条目。

验收：图片不必逐条打开才能辨认；不同图片保留；菜单可键盘操作；撤销不覆盖外部修改。

## 阶段 4：维护退到异常流程

状态：已完成，v0.6.7。

实现：收藏变化、窗口激活和页面可见时每 15 秒自动更新列表；通过读取序号忽略过期结果。列表读取失败不显示空收藏，正文失败可在原地重新读取。修复入口移至设置的高级选项。旧数据升级使用单个入口，显示保存与备份进度；全部保存及完整备份校验后才清理旧副本，并校验升级期间保存位置未切换。成功通知与错误提示分开。

检查：189 项测试、类型检查、生产构建、diff 空白检查通过。覆盖列表与正文重试、自动刷新、过期读取、拒绝授权后恢复、升级中断和备份失败。真实 Chrome 整体视觉和目录交互仍待验收。

- 自动更新首页，移除常驻刷新；失败提供就地重试。
- 索引恢复仅在异常或高级设置中出现，称“修复收藏列表”。
- 旧数据升级收敛为一次流程：预先说明备份及清理，保留完整回读校验与失败恢复。
- 成功、处理中和错误采用不同反馈，隐藏常驻技术说明。

验收：无需主动刷新就能看到新收藏；读取失败不显示为空收藏；升级失败不删除旧数据；拒绝目录权限可恢复。
